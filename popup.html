치지직 싱크 컨트롤러 v0.3.1
치지직 라이브 스트리밍 딜레이를 미세 조절하여 두 방송의 싱크를 맞출 수 있도록 돕는 확장 프로그램입니다.
현재 지연 시간: - 초

사용자의 사양에 따라 버퍼링이 발생할 수 있습니다. 사용법 탭의 설명을 읽고 사용해주세요.

사용법

  • 5초 단위 이동 ← / →
  • 1초 단위 이동 Ctrl + ← / →
  • 0.1초 단위 이동 Shift + ← / →
  • 최신 지점으로 이동 빨리감기 버튼 / 지연시간 초기화 버튼

두 방송의 싱크 맞추는 법

  1. 빨리감기 버튼이나 지연 시간 초기화 버튼을 누른 뒤, 어느 쪽 방송이 더 빠른지 확인해주세요.
  2. 두 방송 중 더 빠른 쪽의 영상 화면을 선택해주세요.
  3. 방향키나 팝업의 이동 버튼을 사용해 두 방송의 싱크를 맞춰주세요.

싱크를 맞췄는데 다시 어긋나는 경우

1. 버퍼링 없이 점점 싱크가 계속 어긋나는 경우 - 현재 지연 시간 뒤에 * 표시가 붙어 있다면 재생속도 보정이 이루어지고 있다는 뜻입니다. 빨리감기 혹은 지연 시간 초기화 버튼을 누른 후 다시 싱크를 맞춰주세요.
- 같은 현상이 반복된다면 기능 탭의 지연 시간 보정 방지를 켜주세요. 2. 화면에 치지직 로고가 나타나며 영상이 버벅거리는 경우 - 단순 인터넷 상태 문제로 인해 버퍼링이 발생한 것이므로 버퍼링이 끝난 뒤 다시 싱크를 맞춰주세요.

기타

- 지연 시간은 브라우저가 받은 가장 최신 데이터와의 기준입니다. 실시간으로 데이터를 받기 때문에 표기가 1초 정도 왔다갔다 할 수 있습니다.
- 지연 시간이 일정 이상 커지면 브라우저가 재생속도를 1.03배로 보정하여 지연 시간을 자동으로 자연스럽게 줄입니다.
- 만약 지연 시간이 너무 커지면 브라우저에서 강제로 빨리감기를 실행합니다.
